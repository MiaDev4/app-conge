# app-conge

Application de gestion des congés.

## Objectif
Ce projet permet de gérer les demandes de congé, de consulter les informations liées aux employés et de suivre les demandes dans une interface simple.

## Stack
- Node.js
- Express / JavaScript
- Base de données SQL

## Installation
```bash
npm install
```

## Démarrage
```bash
node app.js
```

## Structure principale
- `app.js` : point d'entrée de l'application
- `views/` : vues de l'application
- `demande_conge.sql` : script SQL de base
- `package.json` : dépendances et scripts
